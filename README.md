## Dimensions Usage
The dimensions used for each CSS file is based on the Week 3 lecture where:
- Full-sized is 960+ pixels wide
- Tablet is 481-960 pixels wide
- Phone is 480 pixels wide or less 

*Note that the mobile.css is also based on the absolute minimum baseline of 320px as that is the lowest width a phone historically had (iPhone 5/SE)
*Note2 that with the exact 960px conflicts with tablet and full-sized, full-sized only applies to 961+
